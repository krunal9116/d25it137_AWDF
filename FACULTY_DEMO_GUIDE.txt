4. TOP VIVA QUESTIONS & DIRECT ANSWERS
--------------------------------------------------------------------------------

Q1: Why must the AI API be called from the backend instead of directly from React?
A1: Security & Key Isolation. Any JavaScript running in a web browser can be
    inspected by users via DevTools Sources and Network tabs. Putting API keys
    in React exposes them to theft and financial abuse. Routing through Express
    keeps the key secure in server environment variables (process.env.OPENAI_API_KEY)
    and allows the server to sanitize requests and enforce rate limits.

Q2: What is "Graceful Degradation"?
A2: It is an architectural resilience pattern where an application continues to
    operate smoothly with fallback functionality when an external dependency
    fails, rather than throwing fatal error screens. In our project, if OpenAI
    or Gemini times out or quota is exhausted, our local fallback engine
    generates relevant suggestions so the user can still create tasks uninterrupted.

Q3: How do you enforce Responsible AI governance in your application?
A3: 1) Human-in-the-loop: Suggestions are placed in editable fields, never auto-saved.
    2) Transparency: A prominent disclaimer banner alerts users to review AI output.
    3) Data Privacy: Only task titles are sent; no passwords, tokens, or PII.
    4) Resource Protection: Dual-layer rate limiting (server IP tracking + client cooldown).

Q4: What is the benefit of Docker Compose and named volumes?
A4: Docker Compose runs all interdependent services (frontend, backend, database)
    together on a private bridge network with automatic service discovery DNS.
    The named volume (mongo-data) guarantees that database records survive even
    when containers are stopped, removed, or rebuilt.

Q5: Why use an EventEmitter for notifications instead of synchronous code?
A5: To decouple secondary side-effects (like logging, notifications, or email)
    from the main HTTP request-response cycle. The API responds to the user
    immediately (e.g., 201 Created), and the listener processes events in the
    background without adding latency.
