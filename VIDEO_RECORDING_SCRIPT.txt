"Now for the core highlight of Practical 13: External AI Service Integration.

Notice four key engineering and Responsible AI implementations:
First, Key Isolation: The AI API keys reside solely in the backend .env, never 
exposed to browser inspect tools.
Second, Graceful Degradation: If external AI services encounter rate limits, 
outages, or unconfigured keys, our local heuristic fallback engine immediately 
generates contextual descriptions so the user workflow is never interrupted.
Third, Human-in-the-Loop: The suggestion is populated into an editable textarea, 
allowing the user to inspect and edit before committing to the database.
And fourth, Rate Limiting: A 30-second client cooldown and a 10 request-per-minute 
server limit prevent quota exhaustion."
